# Agent Notes

Scope: this file applies to the whole repository.

## Environment

- Use `direnv exec .` once to discover `$DEVENV_PROFILE`, then prepend `$DEVENV_PROFILE/bin` to `PATH` and run project commands directly from that shell.
- Treat `$DEVENV_PROFILE` as the toolchain root. Node, npm, `oxfmt`, `oxlint`, and hook tooling should resolve from that environment path.
- Do not install duplicate formatter or linter binaries into npm unless the project intentionally moves ownership from `devenv` to npm.

Example bootstrap:

```sh
DEVENV_PROFILE="$(direnv exec . sh -lc 'printf %s "$DEVENV_PROFILE"')"
export DEVENV_PROFILE
export PATH="$DEVENV_PROFILE/bin:$PATH"
```

## Frontend Stack

- Use TanStack Start for routing and full-stack React structure.
- Use Effect for typed domain/program modeling and service boundaries.
- Use React Aria Components for interactive UI primitives and accessibility behavior.
- Use Lightning CSS through Vite for CSS parsing and transformation.

## Required Checks

Before finalizing frontend or TypeScript changes, run:

```sh
npm run format:check
npm run lint
npm run typecheck
npm run build
```

For one-shot validation, prefer:

```sh
npm run validate
```

`oxfmt` and `oxlint` are required gates. If they fail, fix the source issue rather than bypassing the check.

## Generated Files

- `src/routeTree.gen.ts` is generated by TanStack Router. Do not hand-edit it; regenerate it through the TanStack/Vite workflow.
- Keep local brainstorming or visual scratch work under ignored local paths such as `.superpowers/`.
