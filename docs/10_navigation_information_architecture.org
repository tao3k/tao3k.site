* Purpose

This contract defines the public website navigation for tao3k, a startup
building To-B AI infrastructure and systems.  Startup is the company stage, not
the audience classification.  The primary audiences are investors, prospective
enterprise customers, developers, and the technical community.

The navigation and destination pages adopt the clarity, progressive disclosure,
visual hierarchy, product storytelling, and conversion paths of mature
enterprise technology websites.  Evidence maturity constrains claims; it does
not turn the site into a project diary or a collection of descriptive essays.
The site still does not replace project documentation, API references, or
implementation RFCs.

:PROPERTIES:

* Secondary navigation contract

opens one stable mega-menu with named entries and a one-line description.  The
menu is not a page duplicate, and it does not use generic decorative icons.

** Interaction standard

Desktop menus open through hover intent and remain open while the pointer moves
between trigger and panel.  Touch and keyboard open through an explicit button
with =aria-expanded=.  The panel has no layout shift, no competing floating
windows, and no click-only hidden navigation.  Mobile presents the same entries
as an accessible accordion.

* Presentation rule

Each page chooses a presentation method that matches its subject.  A running
workflow can use an executable graph.  A shared data interface can use a data
bus.  A knowledge system can use a resource constellation.  No visual renderer
may become the mandatory template for every Tao3k concept.  Brand and standard
marks must use traceable official resources; generic or invented icons are not
substitutes.
