* Purpose and authority

This record maintains dated external evidence for industry pain discussed by tao3k.site. It does not convert news coverage into product verdicts. Stable comparison axes remain in [[file:50.01_comparison_framework.org][Comparison Framework]], and the maintained product set remains in [[file:50.02_community_product_reference_set.org][Community Product Reference Set]].

* Evidence-state vocabulary

- Vendor-confirmed incident :: The responsible vendor has published the incident or postmortem.
- Researcher disclosure :: A security or research team has published methods and coordinated disclosure information.
- Peer-reviewed or institutional research :: A research institution or reviewed publication owns the result.
- Primary industry survey :: The publisher owns the surveyed population and discloses the relevant method.
- Investor-authored market signal :: An investor publishes a dated thesis, benchmark, or portfolio analysis.  It establishes the author's view and activity, not an independent market census or technical verdict.
- Court allegation :: A filed claim or argument that has not become a judicial finding.
- News-reported user signal :: News coverage of user reports that has not established a product-wide defect.
- Resolved :: The responsible source states that remediation is complete.
- Unresolved :: Evidence remains incomplete, contested, or awaiting an authoritative response.

* Public Agent issue evidence

The following records are issue-author observations.  They identify concrete
failure reports and requested primitives; they are not vendor-confirmed
product-wide verdicts.

** 2026-06-07: long-running context requires explicit durable retention

- Source :: [[https://github.com/openai/codex/issues/26889][OpenAI Codex issue 26889: thread context pins]].
- Source type :: Public GitHub design issue aggregating related compaction reports.
- Status :: Open when reviewed 2026-08-09.
- Observed fact :: The issue proposes bounded, persistent thread-scoped context pins after citing repeated reports of constraints, decisions, files, and task state being lost or repeatedly reread after compaction.
- Industry pain :: Conversation summarisation does not establish which organisational obligations remain authoritative after a long-running handoff.
- tao3k relevance :: POO Flow owns explicit organisation and composition; Marlin owns durable runtime state and recovery; Org records retain evidence outside the model context.  The integrated response remains an active maturity claim rather than a shipped complete circuit.

** 2026-06-15: recursive delegation can destroy cost and recoverability

- Source :: [[https://github.com/anthropics/claude-code/issues/68619][Claude Code issue 68619: recursive subagent and lost-work report]].
- Source type :: Public GitHub user report.
- Status :: Open when reviewed 2026-08-09.
- Observed fact :: The author reports recursive subagent spawning, permission-denial cascades, retry storms, high token consumption, and loss of intermediate results when interrupted.
- Industry pain :: Parallelism without bounded topology, permission propagation, durable handoff, stopping conditions, and partial-result recovery can amplify cost without producing accountable work.
- tao3k relevance :: Agent organisation belongs to POO Flow, while execution topology, budgets, interruption, recovery, and receipts belong to Marlin.  Scenario Benchmarks must exercise these failure paths.

** 2026-06-24: selected permission and effective permission can diverge

- Source :: [[https://github.com/openai/codex/issues/29915][OpenAI Codex issue 29915: permission profile persistence]].
- Source type :: Public GitHub bug report with proposed protocol fixes and focused tests.
- Status :: Open when reviewed 2026-08-09.
- Observed fact :: The report describes thread start and resume paths where a selected permission profile may not match the live effective state reflected by the runtime.
- Industry pain :: Interface intent is not an authority record when provenance and effective enforcement can diverge across lifecycle transitions.
- tao3k relevance :: The Authority Envelope must be versioned, scoped, validated, enforced, and included in the execution receipt rather than inferred from a UI or tool connection.

** 2026-07: compaction loops can separate interface state from repository truth

- Source :: [[https://github.com/openai/codex/issues/27588][OpenAI Codex issue 27588: repeated pre-write compaction loop]].
- Source type :: Public GitHub user report.
- Status :: Open when reviewed 2026-08-09.
- Observed fact :: The report describes repeated preflight reads after compaction, hours without edits, reconnect events, and ambiguity about whether backend execution failed, continued, or partially changed files.
- Industry pain :: A transcript does not replace durable phase state, progress evidence, no-progress detection, or a typed safe-stop receipt.
- tao3k relevance :: POO Flow conditions define the intended state machine; Marlin must own resident phase, checkpoint, progress, retry, interruption, and recovery truth.

** 2026-07-28--29: continuation loss can repeat completed work and consume paid capacity

* Main-site use contract

The main site may project a small number of current evidence cards, each with its date, evidence state, source, observed fact, and architectural relevance. It must not use an incident to imply that an entire product category is unsafe, claim that tao3k currently prevents a failure without shipped evidence, or retain a resolved and outdated event as if it were current news.

Every projected pain point must answer:

1. What is directly supported by the source?
2. What remains allegation, inference, or uncertainty?
3. Which general lifecycle boundary does the event expose?
4. Which tao3k doctrine or intended control is relevant?
5. What evidence proves the tao3k capability is available today?

* Maintenance contract

Review fast-moving records monthly. Preserve old records as dated history, mark corrections and vendor responses, and add a new entry rather than silently rewriting the meaning of an earlier event. A record without a current source and evidence state must not appear in the live Comparison surface.
