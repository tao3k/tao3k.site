* Purpose

These marks identify upstream technologies used by the tao3k platform. They do not imply
endorsement, partnership, or ownership by tao3k. The application imports local copies so the
official site does not depend on third-party runtime requests.

* Scheme language mark

Scheme has no single central official logo. The interface therefore combines a code-native lambda
glyph with the official Gerbil mark and labels the runtime stack as Gambit + Gerbil Scheme. It does
not present the lambda glyph as an official project trademark.
